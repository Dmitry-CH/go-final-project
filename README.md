# Итоговый проект

В итоговом проекте реализован веб-сервер и функциональность планировщика задач — аналог TODO-листа.

API содержит следующие операции:

* добавить задачу;
* получить список задач;
* удалить задачу;
* получить параметры задачи;
* изменить параметры задачи;
* отметить задачу как выполненную.

Список выполненных задач:

1. Создание веб-сервера.
    * доп. определена переменная `TODO_PORT`
2. Проектирование и создание БД.
    * доп. определена переменная `TODO_DBFILE`
3. Написание функции для вычисления следующей даты у задачи.
4. Реализация обработчика для добавления задачи.
5. Получение списка ближайших задач.
    * доп. реализован поиск `/api/tasks?search=бассейн` или `/api/tasks?search=08.02.2024`
6. Реализация обработчика для редактирования задачи.
7. Реализация обработчиков при выполнении задачи и её удалении.
8. Подключение аутентификации.

## Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

## Запуск проекта

    env TODO_PASSWORD=qwerty TODO_PORT=8080 go run main.go

Откройте её в браузере по пути `http://localhost:8080/login.html`

## Запуск тестов

    env TODO_PASSWORD=qwerty TODO_PORT=8080 go test -v ./tests

Все настройки для запуска тестов уже определены в файле `tests\settings.go`

## Сборка проекта

    env GOOS=linux GOARCH=amd64 go build -o app

## Сборка Docker image

    docker build -t my-todo:v1 .

## Запуск Docker container

    docker run -p 8080:3000 -e TODO_PASSWORD=qwerty -e TODO_PORT=3000 my-todo:v1

Откройте её в браузере по пути `http://localhost:8080/login.html`
